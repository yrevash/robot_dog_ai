# REVO Robot AI — Complete File Guide

## `src/` — Main Software

| File | What It Does | How to Run |
|---|---|---|
| `face_control_center.py` | **Main app** — GUI with webcam, face recognition, gesture control, robot commands | `python src/face_control_center.py` |
| `face_embedding.py` | CLI tool — capture faces, build face database, recognize faces | See commands below |
| `revo_pi.py` | Headless version for Raspberry Pi (no GUI, optimized) | `python src/revo_pi.py` |
| `capture_faces.py` | Legacy simple face capture (basic, no quality checks) | `python src/capture_faces.py` |

### face_embedding.py commands

```bash
python src/face_embedding.py capture --name Alice --samples 25   # take photos
python src/face_embedding.py build                                # build database
python src/face_embedding.py recognize                            # run recognition
python src/face_embedding.py enroll --name Alice --samples 25     # capture + build in one step
```

## How It Works (Pipeline)

```
Camera -> Detect Face -> Recognize Who -> Vote (6 frames) -> Authorized?
                                                                 |
                                                               YES
                                                                 |
                                                  Detect Hand Gesture -> Send Command to Robot
```

## Idle Time and Power States

Defined in `src/power_state.py`, used by both `src/face_control_center.py` and `src/revo_pi.py`.

| State | Trigger | What Happens |
|---|---|---|
| ACTIVE | Face detected / any activity | Full processing, camera running |
| POWER_SAVE | 15 min idle (no face seen) | Reduced processing |
| POWER_OFF | 30 min total idle | System shuts down camera/resources |

### Frame Skip by State (Raspberry Pi — `src/revo_pi.py`)

| State | Frames Skipped | Meaning |
|---|---|---|
| IDLE | 5 | Process every 5th frame (no face seen recently) |
| DETECTING | 2 | Process every 2nd frame (face detected, verifying) |
| AUTHORIZED | 1 | Process every frame (user verified, watching for gestures) |

### State Transitions (`src/revo_pi.py`)

```
IDLE       -> DETECTING   : face detected in frame
DETECTING  -> AUTHORIZED  : identity confirmed by voting
DETECTING  -> IDLE        : no face for > track_timeout + 1s
AUTHORIZED -> IDLE        : no face for > track_timeout + 1s
```

### Configurable Timers

| Setting | Default | Where |
|---|---|---|
| `idle_to_save_sec` | 900s (15 min) | `src/revo_pi.py`, `src/face_control_center.py` |
| `save_to_off_sec` | 1800s (30 min) | `src/power_state.py` |
| `frame_skip_idle` | 5 | `src/revo_pi.py` |
| Motion gate threshold | 0.8% pixel change | `src/revo_pi.py` (IDLE state only) |

## Quick Start

```bash
# 1. Install dependencies
pip install opencv-contrib-python numpy pillow mediapipe

# 2. Enroll your face
python src/face_embedding.py enroll --name YourName --samples 25

# 3. Launch the app
python src/face_control_center.py
```

All commands run from the project root (`Revo_Robot_AI/`).
